# ECHOES mobile — тестовая версия для iPhone

Лёгкий плеер в стиле ECHOES: ищете любую песню — она играет **потоком**, на телефон ничего не скачивается.
ПК и сервер не нужны: поиск и звук берутся с YouTube прямо на телефоне.

- поиск, очередь, перемешивание, повтор;
- «Мне нравится», плейлисты, история (хранятся только названия — несколько килобайт);
- текст песни, синхронный, если есть (lrclib.net);
- фоновое воспроизведение, экран блокировки, пункт управления, AirPods;
- интерфейс подстраивается под любой iPhone и iPad (портрет и поворот);
- настройки по минимуму: цвет, светлая тема, экономия трафика.

Размер приложения — около 20 МБ. Трафик: ~1 МБ/мин (≈0,4 МБ/мин в режиме экономии).

> Это неофициальный клиент: звук берётся с YouTube в обход официального приложения. Поэтому — только
> установка вручную (Sideloadly / AltStore), в App Store такое не пропустят. Иногда YouTube что-то меняет —
> тогда нужно пересобрать приложение со свежей версией библиотеки `youtube_explode_dart`.

## 1. Собрать IPA (без Mac — в облаке GitHub)

1. Зарегистрируйтесь на [github.com](https://github.com) и создайте репозиторий **`echoes-mobile`**
   (**Public** — облачная сборка тогда бесплатна без ограничений; Private — около 15 сборок в месяц бесплатно).
2. Загрузите туда эту папку. В PowerShell:
   ```
   cd F:\ZHOPA\ECHOES-mobile
   git init
   git add .
   git commit -m "ECHOES mobile"
   git branch -M main
   git remote add origin https://github.com/<ваш-ник>/echoes-mobile.git
   git push -u origin main
   ```
   (при первом push откроется окно входа в GitHub).
3. Сборка запустится сама: вкладка **Actions** → «Build IPA». Ждать ~10–15 минут.
4. Откройте завершённый запуск → внизу **Artifacts** → **ECHOES-ipa** → скачается zip, внутри `ECHOES.ipa`.

Пересобрать вручную: Actions → Build IPA → **Run workflow**.

## 2. Поставить на iPhone

**Sideloadly** (Windows, бесплатно) — [sideloadly.io](https://sideloadly.io):
1. Установите iTunes с сайта Apple (не из Microsoft Store) и Sideloadly.
2. Подключите iPhone кабелем, нажмите «Доверять».
3. Перетащите `ECHOES.ipa` в Sideloadly, введите Apple ID, **Start**.
4. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → **Доверять**.
5. iOS 16+: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → вкл (iPhone перезагрузится).

С бесплатным Apple ID приложение работает **7 дней**, потом его снова ставят тем же способом
(или AltStore переподписывает его сам по Wi-Fi, пока ПК с AltServer включён).
С платным аккаунтом разработчика ($99/год) — год.

```
flutter test test/screenshots_test.dart --run-skipped --update-goldens   # снимки экранов → test/goldens
```

Платформенные папки (`ios/`) не хранятся в репозитории — сборка создаёт их сама (`flutter create`).
